## 文件夹详解

### 00_原始母版（视觉基准，请勿修改）
所有资产的设计基准文件：
- `DreamAI-原始母版-AI效果图.png`：最高质量母版（2048×2048）。
- `DreamAI-原始母版-AI效果图.jpg`：母版的 JPEG 版本（最高质量见同名 `.png`）。
- `DreamAI-浅色图标-原始母版.jpg`：浅色版本母版。

### 01_软件图标_圆角底板（iOS 风格圆角方形）
用于软件 / APP 图标的标准版本，浅蓝白圆角底板，**只有星球符号，没有文字**。
- `DreamAI-icon-16/32/48/64/128/180/256/512/1024/2048/4096.png`：全尺寸透明圆角 PNG。
- `DreamAI-icon-*-白底.png / .jpg`：白底版本，给不支持透明的软件。
- `DreamAI-icon-1024/2048/4096.pdf`：PDF 打印版。

### 02_纯星球符号_透明底（只有星球、无底板）
透明背景的纯图形，**水印、叠加、动画、UI 元素**用它：
- `DreamAI-mark-64…4096-透明底.png`：透明底 PNG，全尺寸。
- `DreamAI-mark-*-白底.jpg`：白底版本。
- `DreamAI-mark-1024/2048/4096.pdf`：PDF 打印版。

### 03_组合标_含字标（图形 + DreamAI 字标）
官方完整组合标识（白底），用于官网页眉、封面、宣传、文档抬头：
- `DreamAI-lockup-1200/2400.png`、`.jpg`、`.pdf`。

### 04_矢量源_SVG
- `DreamAI-icon.svg`：软件图标矢量版（内嵌高分辨率母版，视觉 100% 匹配）。
- `DreamAI-mark.svg`：纯星球符号矢量版。
- `DreamAI-lockup.svg`：组合标矢量版（含矢量文字）。

### 05_PSD分层源文件（Photoshop 可编辑）
- `DreamAI-AppIcon-分层.psd`：底板层 + 星球主体层，可单独开关、改色。
- `DreamAI-Mark-分层.psd`：透明背景层 + 星球主体层。

### 06_favicon（网站图标）
- `favicon.ico`：网站标签页图标（含 16/32/48/64/128/256 多尺寸）。
- `favicon-mark-透明.ico`：透明纯符号版本。
- `apple-touch-icon-180.png`：iOS 主屏图标。
- `icon-512.png`：PWA / 网站高清图标。

### 07_版权与说明
- `DreamAI-Logo-版权与使用说明.md`：中文版权、授权范围、品牌色值、使用规范。
- `DreamAI-Brand-Asset-LICENSE.txt`：英文品牌资产许可。

## 关于 `.jpg` 与 `.jpeg`

早期版本为每个白底图同时导出了 `.jpg` 与 `.jpeg` 两份，两者内容完全相同（逐字节一致），
只是扩展名不同，属于重复文件，已于 2026-10 清理：**统一保留 `.jpg`**。
如果你的旧文档引用过 `.jpeg` 路径，把扩展名改成 `.jpg` 即可，图片内容没有任何变化。

## 视觉特征说明

**DreamAI Logo 核心元素**：
- **球体**：绿色（左上）→ 蓝色 → 紫色（右下）渐变球体，带有立体质感
- **行星环**：粗带状环，从左下蓝色渐变到右上紫色，环绕星球
- **金色四角星**：右上角金色闪光星星
- **流星弧线**：连接星球与星星的紫色小弧线
