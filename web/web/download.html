桌面版多了什么

文档一键生成

Word、Excel、PPT、PDF、Markdown 五种格式，带标题、小节、表格和排版，直接可用。

文件整理

按类型自动归类、统一前缀批量重命名，先预览再执行，只动你选中的文件夹。

编程模式

说一句「做一个前后端待办清单」，它自己建项目、写代码、装依赖、把服务跑起来，报错还会自己修。

安全边界

只能访问你手动选择的文件夹；每一次移动、重命名、保存，都会弹系统确认框。

想让 AI 直接帮你把程序写出来？

切到「编程」模式，描述你要的小程序，Dream 会在工作文件夹里新建项目、逐批生成代码、运行 npm 安装、启动服务并检查输出；报错了它会读日志、改代码、再跑一次，直到跑通。

  • 所有操作都发生在你选择的工作文件夹下的「Dream AI 项目」里
  • 命令白名单 + 完整命令日志（dreamai-commands.log），危险命令会先问你再执行
  • 服务随时可以在对话里一键停止

三步开始

  1. 下载并安装运行 DreamAI-Setup 安装包，按提示完成安装。
  2. 选择工作文件夹在右侧「智能体」面板选一个文件夹，生成的文件会放进去。
  3. 直接说你要什么「文档」模式生成办公文件，「编程」模式直接帮你把项目写出来并跑起来。

常见问题

编程模式需要什么环境？

需要电脑安装 Node.js 20+（nodejs.org）。默认生成零第三方依赖的项目，没有 npm 也能直接运行；需要装包时会检测 npm 并提示。

编程模式会动我电脑上的其他东西吗？

不会。它只能在「工作文件夹 / Dream AI 项目」里创建和修改文件；命令有白名单，危险命令会弹窗确认，所有命令都会写入项目里的 dreamai-commands.log 可随时审查。

能生成哪些文件？

Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）、PDF 和 Markdown。不需要电脑安装 Office。

内容会不会很模板化？

会按你的需求写具体内容，并检测「平台一 / 负责人一」这类占位内容自动重写；生成后还可以继续让 Dream 修改。

要付费吗？

不强制。默认使用免费模型；想用 DeepSeek V3 / R1，在设置里填自己的 API Key，按自己的用量付费。

会不会动我电脑里的其他文件？

不会。桌面版只操作你手动选择的那个文件夹，且只处理它的第一层文件；每个写操作都有系统级确认框。

为什么 Windows 提示「未知发布者」？

安装包暂时没有购买代码签名证书。点「更多信息」→「仍要运行」即可，开源代码可以在 GitHub 查看。

支持 macOS / Linux 吗？

目前只有 Windows 64 位版本，macOS 与 Linux 在计划中。
