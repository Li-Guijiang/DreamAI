Changelog

每次更新，
都更能干活。

从网页对话到桌面智能体，再到记忆、知识库与编程模式。

v1.5.0

2026-10-31

把 2026 年主流的 AI 助理能力补齐到网页与桌面端。

  • 长期记忆：自动识别「记住：……」，跨对话携带偏好。
  • 本地知识库：导入 txt / md / 代码，BM25 检索并在回答下标注来源。
  • Artifact 画布：HTML / SVG / Markdown 代码块一键预览与下载。
  • 联网阅读：读取公开网页正文，带 SSRF 防护。
  • 提示词库与斜杠命令：8 个内置模板，支持保存自己的提示词。
  • 智能路由、用量面板、朗读、PWA 离线壳。

v1.2.0

2026-10-27

桌面端进入「能真正动手」的阶段。

  • 编程模式：建项目、写代码、装依赖、启动服务、读报错并修复。
  • 零依赖默认 + 内置脚手架兜底，没有 npm 也能跑起来。
  • 命令白名单、危险命令确认、dreamai-commands.log。

v1.1.0

2026-10-26

桌面版从「网页套壳」变成真正的办公助手。

  • 文档生成：Word / Excel / PPT / PDF / Markdown，无需安装 Office。
  • 6 类办公模板；占位内容自动检测重写。
  • 无边框 App 外壳 + 右侧智能体面板 + 产物列表。

v1.0.0

2026-10-26

Windows 桌面版 MVP 上线。

  • 本地文件工作台：按类型整理、批量重命名、导出对话。
  • 所有写操作二次确认，只能访问用户选择的文件夹。
